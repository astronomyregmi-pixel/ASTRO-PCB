# ASTRO-PCB
Just a normal PCB based on astrophysics.
---
## 📌 About the project
**What I made:**A circular PCB called *Astro* with custom silkscreen graphics(stars, galaxies) and integrated component.
**Design Tool:** KiCad PCB Editor.
**Purpose:** Built as a badge/ name card project for Hack Club's `#solder-ships` program.
---
## 🔧How I made It
** Schematic and layout:** Designed the schematic connections and laid out components inside a circular board outline in KiCad.
**Component Routing:** Carefully routed power and ground tracks across copper layers(`F .Cu` and `B . Cu`).
**Custom Artwork:** Added custom astrophysics-themed silkscreen graphics and text to the board design.
**DRC optimization:** Resolved Design Rule check (DRC) clearance violations to ensure proper spacing between  traces and pads.
